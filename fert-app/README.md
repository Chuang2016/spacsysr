# 🌾 科学施肥推荐 App

基于**目标产量法（养分平衡法）**的施肥量推荐工具，作物养分参数借鉴 SPACSYS
机理模型的"单位产量养分需求"思想。

## 功能

输入地块信息，输出推荐施肥方案：

- **输入**：作物（水稻/小麦）、地块面积、目标产量、去年产量与施肥量；
  选填土壤化验指标（有机质、pH、碱解氮、有效磷、速效钾），有则推荐更准。
- **输出**：
  - 推荐纯养分量 N / P2O5 / K2O（kg/亩）及全田总量；
  - 折算常用肥料（方案A：尿素+过磷酸钙+氯化钾；方案B：磷酸二铵+尿素+氯化钾）；
  - 基肥 / 追肥分配；
  - 完整计算过程明细（每一步的数字都列出来）；
  - 农艺建议（含 pH、有机质异常提示）；
  - 一键下载 TXT 文本报告。

## 算法原理

```
施肥量(kg/亩) = [目标产量 × 单位产量养分吸收量 − 土壤养分供应量] / 肥料当季利用率
```

- **目标产量需肥量** = 目标产量(kg/亩) / 100 × 每100kg籽粒养分吸收量
  （水稻：N 2.2、P2O5 1.0、K2O 2.7；小麦：N 3.0、P2O5 1.2、K2O 3.0，单位 kg）
- **土壤养分供应量**（按养分独立判断）：
  - 有化验值：化验值(mg/kg) × 0.15 × 校正系数（默认 0.6）
  - 无化验值：去年产量需肥量 − 去年施肥纯养分量 × 当季利用率（用去年数据反推地力）
- **肥料当季利用率**默认：N 35%、P2O5 20%、K2O 50%
- 以上参数均可在 `recommend_fertilizer()` 中自定义（`uptake` / `eff` / `corr`），
  建议用当地田间试验结果校准。

## 运行

```r
install.packages("shiny")   # 只需装一次
shiny::runApp("fert-app")   # 路径换成 app 所在目录
```

也可以不用界面，直接在 R 里调用核心函数：

```r
source("fert-app/R/fert_core.R")
r <- recommend_fertilizer("水稻", area_mu = 10, target_yield = 650, last_yield = 600,
                          last_N = 12, last_P = 5, last_K = 6)
r$fert        # 推荐纯养分量（kg/亩）
cat(r$report_text)   # 完整文本报告
```

## 与 spacsysr 的关系

本 App 的养分平衡框架与 `spacsysr` 包（SPACSYS 土壤生物地球化学过程 R 实现）
互补：`spacsysr` 做机理过程模拟（如 `spacsys_lite_run` 的水–碳氮–作物耦合），
本 App 做面向田间决策的快速推荐。作物养分吸收系数参考了 SPACSYS 作物模块的
参数思想与《中国主要作物施肥指南》常用值。未来可接入 `spacsysr` 做多情景
施肥校验（见 `run_scenarios()`）。

## 注意事项

- 推荐结果供田间决策参考；利用率与校正系数为经验默认值，**务必用当地试验校准**。
- 目标产量较去年增幅超过 30% 时，App 会给出不确定性提示。
