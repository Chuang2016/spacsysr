# 🌾 科学施肥 App 使用教程

## 一、这是什么

一个基于"目标产量法（养分平衡法）"的施肥推荐小工具。
你告诉它：**种什么、种多大面积、想打多少产量、去年打了多少产量施了多少肥**，
它算出今年**氮磷钾各该施多少**，并折算成你买得到的**尿素、二铵、氯化钾**各多少袋。
如果你手头有**土壤化验单**（有机质、pH、碱解氮、有效磷、速效钾），填进去推荐会更准。

> **边界证据**：印度两年水稻大田试验（Reddy et al. 2026, *J. Agric. Food Res.* 31:103309）
> 发现，减氮 25%（97.5 kg N/ha 土施 + 纳米尿素叶面喷施）产量与全量施氮统计等效——
> 推荐量不是越多越好，关键是氮素被作物实际吸收利用。这正是目标产量法按"养分平衡"
> 而非"越多越好"来算推荐量的逻辑。

## 二、安装与启动（Mac）

1. 安装 R（https://cran.r-project.org/，下载 macOS 版本，一路"继续"即可）。
   建议同时安装 RStudio（https://posit.co/download/rstudio-desktop/），界面更友好。
2. 打开 R 或 RStudio，安装 shiny 包（只需做一次）：
   ```r
   install.packages("shiny")
   ```
3. 下载本 App 代码（见文末"代码获取"），解压后在 R 里运行：
   ```r
   shiny::runApp("/path/to/fert-app")   # 把路径换成你解压后的 fert-app 文件夹
   ```
   App 会在默认浏览器中打开。若用 RStudio，也可直接打开 `app.R` 点右上角 **Run App**。

> 不想开界面？也可以只用核心函数（见第七节）。

## 三、输入项说明

| 输入 | 单位 | 说明 |
|---|---|---|
| 作物 | — | 水稻 / 小麦（二选一，养分需求系数不同） |
| 地块面积 | 亩 | 你的田块大小 |
| 目标产量 | kg/亩 | 今年想达到的产量 |
| 去年产量 | kg/亩 | 去年实际产量（用于反推地力） |
| 去年施肥量（N/P2O5/K2O） | kg/亩，纯养分 | 去年施的纯养分量。注意是**纯养分**不是肥料重量：如施了 50kg 尿素/亩，纯氮 = 50 × 46% = 23 kg/亩 |
| 有机质 | g/kg（选填） | 土壤化验单上的"有机质" |
| pH | 选填 | 酸碱度，App 会据此给调酸/调碱建议 |
| 碱解氮/有效磷/速效钾 | mg/kg（选填） | 化验单上的速效养分；填了就用化验值算土壤供肥，不填就用去年数据反推 |

**去年施肥量折纯养分速查**：尿素含 N 46%，磷酸二铵含 N 18%、P2O5 46%，
过磷酸钙含 P2O5 12%，氯化钾含 K2O 60%，复合肥看包装袋标注。

## 四、结果解读

点"计算推荐施肥量"后，你会看到：

1. **推荐纯养分量**：N、P2O5、K2O 各多少 kg/亩，以及全田总计多少 kg。
   还会显示"与去年相比增减"，帮你判断今年是加还是减。
2. **肥料折算**：两种买法
   - 方案A（单质肥料）：尿素 + 过磷酸钙 + 氯化钾；
   - 方案B（二铵+尿素+氯化钾）：先用二铵满足磷，剩下的氮用尿素补。
   每种都给出每亩用量和全田总量，照着买、照着撒即可。
3. **基肥/追肥分配**：水稻氮肥按 基肥:分蘖肥:穗肥 = 5:3:2，
   小麦氮肥 60% 基施、40% 返青–拔节追施；磷肥全部基施。
4. **计算过程明细**：每一步的数字都列出来，可核对、可存档。
5. **农艺建议**：如 pH 异常、有机质偏低、目标产量增幅过大等提示。
6. **下载报告**：点"下载推荐方案"得到 TXT 文本报告，可打印或发给家人/农技员。

## 五、完整示例演算

输入：水稻，10 亩，目标 650 kg/亩；去年 600 kg/亩，去年施肥 N 12、P2O5 5、K2O 6 kg/亩；无化验值。

App 内部计算（与"计算过程明细"完全一致）：

```
① 目标产量需肥量 = 目标产量/100 × 每100kg籽粒吸收量
   N：650/100 × 2.2 = 14.30 kg/亩
   P2O5：650/100 × 1.0 = 6.50 kg/亩
   K2O：650/100 × 2.7 = 17.55 kg/亩

② 土壤供肥量（无化验值，用去年数据反推）
   去年产量需肥量：N 13.20、P2O5 6.00、K2O 16.20 kg/亩
   土壤供应 = 去年需肥 − 去年施肥 × 当季利用率（N 35%、P2O5 20%、K2O 50%）
   N：13.20 − 12×0.35 = 9.00 kg/亩
   P2O5：6.00 − 5×0.20 = 5.00 kg/亩
   K2O：16.20 − 6×0.50 = 13.20 kg/亩

③ 推荐施肥量 = (目标需肥 − 土壤供应) / 当季利用率
   N：(14.30 − 9.00)/0.35 = 15.14 kg/亩
   P2O5：(6.50 − 5.00)/0.20 = 7.50 kg/亩
   K2O：(17.55 − 13.20)/0.50 = 8.70 kg/亩

④ 折算肥料（方案B）
   磷酸二铵 = 7.50/46% = 16.3 kg/亩（带入 N：16.3×18% = 2.93 kg/亩）
   尿素 = (15.14 − 2.93)/46% = 26.5 kg/亩
   氯化钾 = 8.70/60% = 14.5 kg/亩
   全田（10 亩）：二铵 163 kg、尿素 265 kg、氯化钾 145 kg
```

## 六、进阶：自定义参数

默认的养分吸收系数、肥料利用率、土壤校正系数是全国常用经验值。
如果你有当地试验数据，可以在 R 里直接调用核心函数并传入自定义参数：

```r
source("fert-app/R/fert_core.R")

# 自定义：每100kg籽粒吸收量(N,P2O5,K2O)、当季利用率、土壤校正系数
r <- recommend_fertilizer(
  "水稻", area_mu = 10, target_yield = 650, last_yield = 600,
  last_N = 12, last_P = 5, last_K = 6,
  uptake = c(2.3, 1.0, 2.8),   # 当地水稻品种实测吸收系数
  eff    = c(0.40, 0.22, 0.55), # 当地肥料利用率试验值
  corr   = c(0.65, 0.60, 0.60)  # 当地土壤校正系数
)
r$fert                 # 推荐纯养分量（kg/亩）
r$prod_B               # 方案B肥料折算表
cat(r$report_text)     # 完整文本报告（可重定向保存）
```

## 七、常见问题

- **Q：没有去年的施肥记录怎么办？**
  A：去年施肥量填 0，App 会把去年产量的全部养分需求都算成土壤供应，
  推荐量会偏保守（偏多）。有条件还是建议找准去年的大致用量。
- **Q：只有部分化验指标（如只有有效磷）怎么办？**
  A：有哪个填哪个。App 按养分独立判断：有化验值的用化验值算，
  没有的用去年数据反推，两者可以混用。
- **Q：推荐量是负数怎么办？**
  A：不会。土壤供应超过目标需求时，App 按 0 计，并在"计算过程"中如实列出。
- **Q：经济作物（蔬菜/果树）能用吗？**
  A：目前只内置水稻、小麦的养分吸收系数。其他作物可用第六节的自定义参数
  传入该作物的吸收系数后使用。
- **Q：结果和农技站推荐的不一样？**
  A：正常。利用率、校正系数各地差异大，本工具默认用全国常用值；
  建议用当地测土配方施肥的校正系数替换默认值后再用。

## 八、注意事项

1. 本工具为**决策参考**，不是农艺处方；大面积应用前建议先小面积验证。
2. 化肥价格波动大，方案A/B 可按当地价格择优选用。
3. 氮肥建议分次深施，避免一次撒施过大；稻田避免大水漫灌——
   在保产的同时可减少 N2O 排放。
4. 目标产量定得越高，推荐量越大；增产超过去年 30% 时请结合品种与田管水平谨慎决策。
